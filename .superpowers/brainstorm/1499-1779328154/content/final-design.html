▸ Agent State Machine PORTED
AgentRuntimeState
processing idle

ใช้ AgentStateTracker จาก repo โดยตรง — ตรวจจากการ stream Claude API chunks แทน PTY output

Idle Tier System
fresh (0–30s) lingering (30–90s) deep (90s+)

interval timer เหมือน repo — fresh=idle, lingering=sleepy, deep=sleepy animation ช้าลง

resolveCharacterEmotion()

Port ตรงๆ จาก repo — map agentState + idleTier → CharacterEmotion per character

Emotion Override

เพิ่มใหม่ — Claude ใส่ [emotion:excited] ใน response → override อารมณ์ชั่วคราว 3s แล้วกลับ resolved emotion

▸ Socket.io Event Protocol
C→S send_message {conversationId, content} — user ส่ง message
S→C agent_state {characterId, state: 'processing'|'idle', idleTier?} — เหมือน type:"state" ใน repo
S→C message_chunk {conversationId, chunk, messageId} — streaming text chunk เหมือน type:"output"
S→C message_done {conversationId, messageId, fullContent, emotion?} — stream จบ
S→C emotion_override {characterId, emotion} — Claude ระบุ emotion พิเศษ
C→S join_conversation {conversationId} — subscribe เพื่อรับ events ของ conversation นั้น
▸ Data Flow
1
User ส่งข้อความ → send_message event → Nest.js บันทึก user message ใน PostgreSQL
2
Nest.js emit agent_state: processing → frontend เปลี่ยน emotion → thinking + anime.js burst
3
Nest.js เรียก Claude API พร้อม system prompt ของ character + conversation history → stream เริ่ม
4
แต่ละ chunk → emit message_chunk → frontend append text, scan หา [emotion:X]
5
ถ้าเจอ [emotion:X] → emit emotion_override → anime.js burst + swap image ชั่วคราว 3s
6
Stream จบ → บันทึก assistant message → emit message_done + agent_state: idle
7
Frontend AgentStateTracker เริ่มนับ idle tier: 30s=lingering, 90s=deep → emotion เปลี่ยนไปเอง
▸ anime.js Animation System
idle 😊

loop: float translateY -6px 3s ease-in-out

thinking 🤔

loop: tilt rotate ±3° 2.5s + float

victory 🎉

burst: jump -20px + scale 1.2 + rotate 5° แล้ว loop bounce

crying 😢

burst: shake X, loop: droop +4px 4s ช้า

excited ✨

burst: glow + jump, loop: fast bounce 0.6s

sleepy 😴

loop: slow sway ±2° 5–7s (deeper = slower)
