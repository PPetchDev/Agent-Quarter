# /agent-ui-polish

Purpose:
Improve UI quality without changing product scope.

Use:
- ai/skills/impeccable.md
- ai/context-packet.md if available

Allowed changes:
- Layout
- Spacing
- Typography
- Interaction states
- Visual consistency
- Responsiveness
- Accessibility improvements

Forbidden changes:
- New business logic unless required for UI state
- Replacing stack
- Large redesign without explicit task
- Removing existing features

Required output:
1. UI verdict
2. Patch plan
3. Files changed
4. Visual risks
5. Test command
